# The difference between /one and /team

`/one` is an account-based subscription that follows you across every UI Color Palette platform; `/team` is a license-based system for distributing several seats at once, and is Figma-only for now.

{% hint style="info" %}
This is documented once, for every UI Color Palette platform — see **[Manage your license](../../general/user-management/manage-your-license.md)**.
{% endhint %}
