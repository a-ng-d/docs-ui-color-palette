# How UI Color Palette on Figma works

{% hint style="info" %}
The `Local Master` / `Local Instance` / `Remote Master` model is documented once, for every UI Color Palette platform — see **[How UI Color Palette works](https://docs.ui-color-palette.com/general/introduction/how-ui-color-palette-works)**.
{% endhint %}

On Figma, palettes are stored on the selected document page (the `Local Master`), and can be saved to the cloud (the `Remote Master`) for reuse across Penpot, Sketch, Framer, and the Web App.

To learn more, see [Palette publication lifecycle](https://docs.ui-color-palette.com/general/introduction/palette-publication-lifecycle).
