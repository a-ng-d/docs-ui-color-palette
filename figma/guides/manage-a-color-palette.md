# Manage a color palette

{% hint style="info" %}
Adjusting the color scale, changing source colors, creating color modes, and adjusting colors/contrast are documented once, for every UI Color Palette platform — see **[Manage a color palette](https://docs.ui-color-palette.com/general/guides/manage-a-color-palette)**.
{% endhint %}

## Color modes and Figma's variable mode limit

You can create as many color modes as you need in the palette itself, but the more modes you manage, the more limits you might meet when syncing them to local variables, since Figma variable modes are capped per plan:

* In Figma Starter, you cannot add more than 1 variable mode
* In Figma Professional and Organization, you cannot add more than 10 variable modes

Learn more by consulting [Figma pricing](https://www.figma.com/pricing/). This limit is specific to Figma's variables system — see [Sync a color palette to the local library](sync-a-color-palette-to-the-local-library.md).
