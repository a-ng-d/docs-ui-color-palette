# Plans

UI Color Palette is a freemium tool that can provide sufficient services to create and manage palettes.

<table><thead><tr><th>Plan</th><th>Includes</th></tr></thead><tbody>
<tr><td><strong>UI Color Palette /basic</strong></td><td><ul><li>Explore every feature before subscribing</li><li>Up to 3 palettes per page or document</li><li>Up to 5 source colors</li><li>Up to 6 steps</li><li>Up to 2 color modes</li><li>Community palettes</li><li>Publication</li><li>CSS export</li></ul></td></tr>
<tr><td><strong>UI Color Palette /pro</strong></td><td><ul><li>/basic features, without volume limits</li><li>Unlimited palettes, source colors, steps, color modes</li><li>Sync with the local library (styles, variables, and — on Penpot — design tokens)</li><li>Palette documentation generation</li><li>Code export (Tailwind, SCSS/Less, Apple, Android, DTCG… — Framer gets a narrower set: CSS, Less, Tailwind, and JSON tokens only)</li><li>Advanced accessibility tools (contrast report, intervals, filter)</li><li>Presets</li></ul></td></tr>
</tbody></table>

{% hint style="info" %}
"Palettes per page or document" is scoped the same way as described in [Understanding free and Pro](../introduction/free-and-pro.md) — palettes are scoped per page on Figma and Penpot, and per document on Sketch and Framer, following each platform's own document model.
{% endhint %}
