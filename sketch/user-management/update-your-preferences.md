# Update your preferences

{% hint style="info" %}
What each preference does, and which platforms expose which ones, is documented once, for every UI Color Palette platform — see **[Update your preferences](https://docs.ui-color-palette.com/user-management/update-your-preferences)**.
{% endhint %}

On Sketch, both the local styles and the local variables synchronization preferences are available, alongside the language preference.

{% hint style="warning" %}
Sketch matches variables by their name, not by an identifier. If you rename a source color, the next sync cannot find the variables created under the old name: it creates new ones, which lose the link with the published ones.
{% endhint %}
