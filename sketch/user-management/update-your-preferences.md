# Update your preferences

{% hint style="info" %}
What each preference does, and which platforms expose which ones, is documented once, for every UI Color Palette platform — see **[Update your preferences](../../general/user-management/update-your-preferences.md)**.
{% endhint %}

On Sketch, both the local styles and the local variables synchronization preferences are available, alongside the language preference.

{% hint style="warning" %}
The current behavior of Sketch cannot replace previous variables with the new ones. So, the new variables will lose the link with the previously published ones.
{% endhint %}
