# Palette publication lifecycle

Publishing a palette moves it through a lifecycle shared by every UI Color Palette platform — a `Local Master` and a `Remote Master`, plus the statuses (`No changes`, `Local changes`, `Remote changes`, `Unpublished`, `Not found`, `Waiting…`) that tell you at a glance what action to take next.

{% hint style="info" %}
This is documented once, for every UI Color Palette platform — see **[Palette publication lifecycle](../../general/introduction/palette-publication-lifecycle.md)**.
{% endhint %}
