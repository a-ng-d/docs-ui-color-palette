# Export a color palette to code

Export every shade/tint of your palette to CSS, SCSS/Less, Tailwind, Apple, Android, spreadsheets, or design tokens (native, DTCG, Style Dictionary) — the full set of formats and their `/pro` requirements are the same on every platform that supports export.

{% hint style="info" %}
This is documented once, for every UI Color Palette platform — see **[Export a color palette to code](../../general/guides/export-a-color-palette-to-code.md)**.
{% endhint %}
