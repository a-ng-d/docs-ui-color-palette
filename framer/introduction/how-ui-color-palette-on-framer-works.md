# How UI Color Palette on Framer works

{% hint style="info" %}
The `Local Master` / `Local Instance` / `Remote Master` model is documented once, for every UI Color Palette platform — see **[How UI Color Palette works](../../general/introduction/how-ui-color-palette-works.md)**.
{% endhint %}

Unlike Figma, Penpot, and Sketch, Framer has no document-level storage for palettes. Palettes are stored in your browser's local storage rather than inside a document (the `Local Master`) — they're strictly linked to that browser and can't be shared with teammates unless you publish the palette to the cloud (the `Remote Master`).

To learn more, see [Palette publication lifecycle](palette-publication-lifecycle.md).
